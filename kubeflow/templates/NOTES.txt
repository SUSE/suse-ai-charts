BACKUP & RESTORE (MariaDB / KFP metadata)
-----------------------------------------

Backups run daily at 02:00 UTC (configurable via pipelines.mariadb.backup.schedule).
Backup files are stored on PVC mariadb-backup-pvc in namespace {{ .Release.Namespace }}.

To list backups:
  kubectl exec -n {{ .Release.Namespace }} deploy/mysql -- ls /backup/

To restore a backup:
  kubectl exec -n {{ .Release.Namespace }} deploy/mysql -- \
    sh -c "mariadb --ssl=false -u root < /backup/<filename>.sql"

To disable backups (resource-constrained clusters):
  Set pipelines.mariadb.backup.enabled=false in your values override.

TROUBLESHOOTING
---------------

If you encounter issues:

1. Check pod status:
   kubectl get pods -n {{ .Release.Namespace }}

2. Check logs:
   kubectl logs -n {{ .Release.Namespace }} deployment/<component-name>

3. Check Istio ingress:
   kubectl get svc -n istio-system istio
