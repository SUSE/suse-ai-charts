NEXT STEPS
----------

1. Create your first notebook:
   - Go to Notebooks in the dashboard
   - Click "New Notebook"
   - Select a container image and resources

2. Create a pipeline:
   - Go to Pipelines in the dashboard
   - Upload a pipeline or use the SDK

3. For production:
   - Change ALL default credentials (see SECURITY WARNING above)
   - Configure OIDC authentication with an external identity provider
   - Set up TLS certificates (set kubeflow-istio-resources.tls.source=selfSigned|letsEncrypt|secret)
   - Configure persistent storage with a production-grade StorageClass
   - Set resource quotas per namespace
   - NetworkPolicies are enabled by default; disable with networkPolicies.enabled=false
     on CNIs without NetworkPolicy support
